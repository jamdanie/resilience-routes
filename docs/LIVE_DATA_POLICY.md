# Live Data and Sensitive Information Policy

Resilience Routes V5 does not ingest or display:

- Live aircraft or vessel positions
- Law-enforcement or military movements
- Non-public critical-infrastructure locations
- Emergency response locations
- Real-time crowd tracking
- Personal data
- Restricted security information

Future external data features require source licensing, privacy review, rate-limit planning, attribution, validation, failure handling, and an explicit educational need.
