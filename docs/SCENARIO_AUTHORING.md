# Scenario Authoring Guide

A strong inject contains a hazard category, target node, concise operational summary, measurable verified signal, learning purpose, initial damage, three credible choices, and cascading consequence.

## Writing principles

- Avoid one obviously correct moral answer.
- Make every credible option carry a cost.
- Keep on-screen text short enough to read during play.
- Separate facts from assumptions.
- Explain consequences without shaming the player.
- Use reviewed sources when scenarios make real-world factual claims.
