# Roadmap

## Release 3 — Game-ready static exercise

Timed decisions, fog of war, advisors, autosave, achievements, exportable after-action review, facilitator documentation, and accessibility settings.

## Release 4 — Campaign and content expansion

Multiple regional missions, randomized event decks, trade-partner and mutual-aid cards, persistent campaign consequences, original team artwork and sound, state-level exercise mode, and facilitator-controlled inject sequencing.

## Release 5 — Optional connected platform

A separately approved backend would support shared classroom sessions, role-based multiplayer, facilitator dashboards, authenticated cohorts, aggregated results, and optional reviewed external feeds.
