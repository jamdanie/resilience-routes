# Milestone 2 — Scenario Learning

This milestone improves the educational experience inside each disruption scenario.

## Added

- A four-step cascading-effect chain that shows how an incident moves through connected systems.
- Plain-language definitions, examples, and reasons for each scenario term.
- A complete explanation for the selected option and, when needed, the recommended response.
- A worked resilience calculation using the exact current score and difficulty values.
- A plain-language reason for each mathematical operation.
- A shorter calculation shown only after the complete method.
- Score details in the after-action report.

## Gameplay

The scenario count, decision choices, difficulty settings, and scoring rules are preserved.
