# Milestone 1 — Mission Experience

This branch adds a guided three-step mission briefing without changing the Phaser simulation engine.

## Included

- Situation and mission-objective briefing
- Plain-language definitions for node, disruption, cascading effect, continuity, capacity, and resilience
- Written scoring formula and a full worked example
- Shorter scoring method shown only after the full explanation
- Difficulty cards with clear descriptions of timers, hints, starting resilience, recovery, and penalties
- A Review Mission Briefing button in Mission Control
- Responsive layouts for desktop, tablet, and mobile

## Test checklist

1. Open the landing page.
2. Select **Begin Mission Briefing**.
3. Move through all three briefing steps.
4. Change the difficulty and enter Mission Control.
5. Confirm the Mission Control difficulty selector matches the briefing choice.
6. Select **Review Mission Briefing** and confirm the briefing reopens.
7. Launch the regional scenario and verify existing gameplay still works.
8. Run `npm run build`.
